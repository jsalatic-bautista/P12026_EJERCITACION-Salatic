# Listas dentro de diccionarios

Crear un diccionario que se llame "netflix". En él, cargar como claves distintos géneros de películas ('acción', 'terror', 'comedia', ...)

Cada género tendrá cargada una lista vacía como valor, de la siguiente forma:

netflix = {
    'acción': [],
    'terror': [],
    'comedia': []
}

Generar un menú que permita cargar una película a cada género elegido, en formato STRING, y que además deje ver el catálogo de películas completo.
